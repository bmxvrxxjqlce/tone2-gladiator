## Overview

Tone2 Gladiator is a versatile wavetable synthesizer with an enormous sound library covering leads, pads, basses, and sound effects, driven by a highly efficient synthesis engine.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Tone2 Gladiator** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Wavetable Engine** | 256-harmonic wavetables with real-time morphing and scanning |
| **Preset Library** | Over 2000 factory presets spanning every genre and style |
| **Modulation Bus** | 12 LFOs and 6 envelopes with free routing to any destination |
| **Effects Chain** | Built-in chorus, reverb, delay, and EQ post-processing |
